LESSON 01

Transformer 数据流：先盯住 shape

直觉

语言模型反复做两件事：让 token 互相交换信息，再对每个位置独立变换通道。残差把新信息加回原表示，最终投影为下一个 token 的分数。

Shape

(B,T) 的整数 token 经 embedding 变为 (B,T,D)；attention 和 FFN 保持外部 shape；lm head 得到 (B,T,V)。

公式 / 例子

x₀ = Embedding(ids) + Position
x′ = x + Attention(Norm(x))
x″ = x′ + FFN(Norm(x′))

选择任一步骤查看它保留和改变的维度。

LESSON 02

Attention：共享什么，保留什么

直觉

Q 是“我在找什么”，K 是“我提供什么索引”，V 是“命中后取走的内容”。MHA/GQA/MQA 改变 KV 头共享程度；线性与稀疏注意力改变历史信息的组织或选择方式。

Shape

标准头形状为 Q:(B,Hq,T,Dh)、K/V:(B,Hkv,T,Dh)。GQA 令多个 Q 头共享一组 KV；MQA 令所有 Q 头共享单组 KV。

公式 / 例子

softmax(QKᵀ / √Dh + causal mask)V。因果 mask 不允许位置 t 读取未来；它不改变张量保存历史的需求。

注意力拓扑切换

选择注意力类型
Q→K₁ V₁ · K₂ V₂ · K₃ V₃→O

MHA：每个 Q 头有独立 K/V 头，表达自由度高，KV cache 最大。

理解检查：哪种拓扑通常是 MHA 与 MQA 的折中？

LESSON 03

KV Cache：省投影，不等于 O(1) 解码

直觉

生成新 token 时，历史 K/V 不变，可以缓存以避免重投影。但 full attention 的新 Q 仍需与历史 K 做匹配并聚合 V，所以 decode 计算仍随历史长度线性增长。

Shape

展开 cache 常见 shape 为 (B,Hkv,T,Dh) 的 K 与 V。MLA 可以先存 latent，但当前 reference 实现若在写 cache 前展开，就必须按展开 shape 计。

公式 / 例子

bytes = B × L × T × Hkv × (Dk + Dv) × dtype_bytes。GB 使用 10³，GiB 使用 2¹⁰；二者不能混写。

边界：MiniMind 的 KV cache 只避免历史 K/V 重投影；YaRN 默认关闭，32K 是配置上限，1M 超出配置。

KV / 状态计算器

默认示例：MiniMind，32K，BF16，reference。

结果按 B 个请求、每请求 T 个 token 计算，分别列出组成、公式、GB/GiB、完整性和证据口径；不代表 GPU 实测占用。

理解检查：有 KV cache 是否意味着 full attention decode 为 O(1)？

LESSON 04

MoE：少算专家，不代表少通信

直觉

Router 为每个 token 选择 top-k 专家。专家参数可以分散在设备间，因此 token 激活要 dispatch 到被选专家，再 combine 回原设备。

Shape

输入激活 (B,T,D) 选 top-k 后，在朴素上界里产生 k 份路由项。AllToAll 传的是复制后的激活，不是专家权重。

公式 / 例子

remote bytes = B × T × D × k × activation_bytes × remote-route fraction。Gb/s 是 bit/s，GB/s 是 byte/s，相差 8 倍；有效带宽还要乘利用率。

FP4 专家权重不会自动减少激活通信；只有激活本身量化或改变路由/布局才会影响这部分 bytes。

AllToAll 理论下限

结果仅为单向 dispatch 下限，不包含 combine、协议、拥塞和负载不均。
理解检查：top-k AllToAll 首先复制并发送什么？

LESSON 05

推理系统：把“可以”与“当前实现”分开

直觉

模型架构只决定可用的计算图。TP、EP、PD 分离、量化 kernel 和 speculative decoding 是运行时选择，不能从一个配置字段推导出真实性能。

Shape

TP 切矩阵维度并聚合部分输出；EP 按专家路由 token；PD 分离迁移的是 cache/state，而非抽象“上下文”。

公式 / 例子

lower-bound time = bytes / effective bandwidth。这里只能给理论下限；没有拓扑、并发和协议数据就不能声称延迟实测。

证据阅读：配置、源码、推导、部署

直觉

Shape

检查 cache 时沿投影后的实际张量走：先看写入 cache 的位置，再读那一刻 K/V 的 shape；不要看到 latent 投影就默认 cache 也存 latent。

公式 / 例子

Qwen 的官方名称是 Qwen3.6，而 config 复用 qwen3_5 实现。这是官方实现复用，不是名称冲突。

01 / TEACHING BASELINE

nanoGPT

查看来源

解决什么：用最少代码展示 GPT 闭环：embedding、因果 MHA、MLP、残差和语言模型损失。

关键替换
无 KV cache；绝对位置 embedding；输入输出权重共享。
训练目标
源码事实 target shift 在数据加载阶段：x 取当前位置，y 取后移一位；模型 forward 直接对齐 logits 与 targets。
缓存口径
reference 为“没有 cache”；标准 MHA cache 只能标为理论假设。
02 / MODERN SMALL MODEL

MiniMind

查看来源

解决什么：以教学规模展示 RMSNorm、RoPE、GQA、SwiGLU 与生成 cache。

关键参数
配置值 8 层、8 个 Q 头 / 4 个 KV 头；最大位置 32K。
位置外推
YaRN 默认关闭；只有显式开启 inference rope scaling 才使用该分支。
缓存口径
源码事实 保存未 repeat 的 GQA K/V。KV cache 避免历史 K/V 重投影，但 full attention decode 仍随历史线性增长；1M 超出配置。
03 / HYBRID ATTENTION

Qwen3.6-27B

查看来源

解决什么：用 48 个 Gated DeltaNet 层承接长历史状态，用 16 个全注意力层保留精确检索。

名称与实现
官方材料 官方名称确为 Qwen3.6；官方 config 复用 qwen3_5 实现，这不是名称冲突。
输出
配置值 tie_word_embeddings=false，因此是独立 lm_head。
缓存口径
源码事实 需分列全注意力 K/V、FP32 recurrent state 与 combined QKV convolution state；精确 byte 由计算器按 B/T/dtype 推导。
04 / MLA + DSA

GLM-5.2

查看来源

解决什么：用 MLA 低秩投影与 DSA top-k 降低长上下文计算，并让若干层共享索引结果。

关键参数
配置值 78 层；按 indexer_types 仅 21 层实例化 Indexer，其余层复用。
reference
源码事实 当前 HF/reference 在 cache update 前把 K/V 展开，因此按展开 K/V shape 计；Indexer key cache 另算。
optimized
推导 576 维 latent cache 属优化/理论口径，不是当前 HF cache 行为。
05 / LINEAR + MULTIMODAL MOE

Kimi-K3

查看来源

解决什么：以 KDA 递归状态覆盖多数层，以 Gated MLA 保留全局注意力，并组合超大 MoE 与视觉输入。

层与视觉
官方材料 首层 Dense、其余 92 层 MoE；视觉塔官方参数量 401M。
reference
源码事实 当前官方 HF/reference cache 拼接展开后的 K/V；精确 byte 由计算器推导。
optimized
推导 优化/理论口径仍需保存 512 维 latent 与参与 key 的 64 维 remainder，共 576 维；KDA recurrent/conv 未完整计量时只显示小计。
06 / COMPRESSED SPARSE ATTENTION

DeepSeek-V4-Flash-0731

查看来源

解决什么：把 43 层主干分配给滑窗、4 倍与 128 倍压缩历史，以单 KV 头和稀疏选择控制长上下文成本。

压缩分布
配置值 主干为 2 个 ratio=0、21 个 ratio=4、20 个 ratio=128。
cache
源码事实 reference buffer 按运行时 max_seq_len/max_batch_size 预分配；attention core 与 FP32 Compressor state 分列，Indexer cache 单列。部署假设 官方示例组合为 core FP8 与 Indexer raw FP4 payload；量化小计不含 scale/metadata 与 packing/alignment。
DSpark
HF 主 config、三层 inference 快照与 vLLM 的 7 speculative tokens 分属不同入口，见课程版本边界。
