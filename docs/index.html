🔬 Gated DeltaNet 核心机制 ▶
解决问题:全注意力 KV cache 随序列线性增长,1M上下文显存爆炸。线性注意力用固定大小状态矩阵替代,KV cache 恒定。
维度MiniMind GQAQwen3.6 DeltaNet
状态KV cache 随T增长状态矩阵恒定 (48,128,128)
计算复杂度O(T²·d)O(T·d²) 递推
长序列显存O(T)O(1)
精确检索高(精确attention)略低(有损压缩)

Delta rule 公式 [源码事实 modeling:369-380]:

S_t = diag(g_t)·S_{t-1} + β_t·(v_t - S_{t-1}·k_t)·k_tᵀ
o_t = q_t · S_t
g = -exp(A_log)·softplus(a+dt_bias) Mamba2式衰减门; β = sigmoid(b) 写入门; (v-Sk) 是delta减法项实现定向覆盖
🔬 两套输出门控 ▶
层类型门控激活实现行号
线性注意力(DeltaNet)swish/siluRMSNormGated: RMSNorm(o)·silu(z)modeling:197,558
全注意力(GQA)sigmoidattn_output · sigmoid(gate)modeling:717
⚠️ 命名易误读：output_gate_type=swish 描述的是线性注意力的门控，不是全注意力层。全注意力用 sigmoid（硬编码在 q_proj 翻倍中）。
