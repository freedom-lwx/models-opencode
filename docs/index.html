nanoGPT · 124M · 最小GPT教学实现

nanoGPT 是 Karpathy 用 ~300 行 PyTorch 实现的最小 GPT。它保留了 2018 年 GPT 的全部核心选择:LayerNorm + 绝对位置编码 wpe + MHA(Q=K=V 等宽)+ GELU MLP(2层无门控) + weight tying。

数据流:input_ids (B,T) -> wte + wpe 得到 (B,T,d) -> 进入 12 个 Block,每个 Block 内 LayerNorm -> CausalSelfAttention -> +残差 -> LayerNorm -> MLP -> +残差 -> ln_f -> lm_head 输出 logits (B,T,V) -> 训练时算 cross_entropy(shift),推理时只取最后位置采样。

关键缺陷:无 KV Cache(每步重算全部K/V)、绝对 wpe 不可外推(超 block_size 越界)。这些是后续 MiniMind 和前沿模型逐一解决的问题。

MiniMind · 64M · 现代小模型(对齐Qwen3生态)

MiniMind 把 nanoGPT 的每个"2018年组件"替换为现代等价物,同时保持可读性。LayerNorm->RMSNorm,绝对wpe->RoPE+YaRN,MHA->GQA(8Q/4KV),GELU MLP->SwiGLU,无 cache->有 KV Cache。

数据流:input_ids (B,T) -> embed_tokens 得 (B,T,d)(无 wpe,位置由 RoPE 注入) -> 从 past_kv 推断 start_pos -> 8 个 Block,每个内 RMSNorm -> Attention(GQA+KVcache) -> +残差 -> RMSNorm -> SwiGLu FFN -> +残差 -> RMSNorm -> lm_head -> generate()(KV cache + temp + top_k + top_p + rep_penalty + EOS + streamer)。

Attention 内部:q_proj(8头)/k_proj,v_proj(4头) -> q_norm/k_norm -> RoPE -> cat(past_kv) 拼接历史 -> repeat_kv(4->8) 广播KV头匹配Q头 -> SDPA -> o_proj。decode 时只传 1 个新 token,这是 KV cache 的核心收益。

Qwen3.6-27B · Dense混合注意力 · 多模态

Qwen3.6-27B 是 Dense 模型(无MoE),核心创新是混合注意力:64层中 48层用 Gated DeltaNet(线性注意力,KV恒定)+ 16层用 Gated GQA(全注意力,精确检索),每4层一组(3线性+1全)。

数据流:input_ids + pixel_values -> ViT(27层)编码图像 -> masked_scatter 注入文本 embedding -> 计算 MRoPE(3D位置 T,H,W=[11,11,10]) -> 64层 Block -> lm_head -> 可选 MTP 推测解码。

Gated DeltaNet 内部:4个投影 in_proj_qkv/z/b/a(Q16头/K16头/V48头) -> short conv k=4 SiLU(局部混合) -> delta rule 递推(S_t = diag(g)·S + β·(v-S·k)·k,状态 48x128x128 恒定) -> RMSNormGated silu(z) 输出门。线性注意力 KV cache 不随序列增长。

Gated GQA 内部:q_proj翻倍(一半做query一半做gate) -> q_norm/k_norm -> RoPE partial 0.25(只旋转64/256维) -> attention -> × sigmoid(gate) 输出门控。两套不同的门控:线性silu / 全sigmoid。

GLM-5.2 · 753B · MoE + MLA + DSA + IndexShare

GLM-5.2 是 753B MoE 模型(78层,前3层Dense后75层MoE,256专家/8选/1共享)。架构继承 DeepSeek-V3.2(modular 4处 MAIN DIFF 全围绕 IndexShare),唯一原创是 IndexShare。

数据流:input_ids -> embed 154880x6144 -> RoPE interleave -> 3层Dense + 75层MoE -> lm_head -> MTP。

MLA 注意力内部:Q走双压缩链 q_a_proj(6144->2048) -> q_b_proj(2048->16384) 解压到64头x256;KV走 kv_a_proj(6144->576) 压缩50x -> kv_b_proj(512->28672) 解压。Q/K拆 nope(192)+rope(64),RoPE只作用于64维。

DSA + IndexShare:32个索引头用 ReLU(QKᵀ) 打分(非softmax,产生稀疏非负分),跨头加权后 top-2048 选key。IndexShare:21层full(算索引) + 57层shared(复用上层索引,indexer=None),省73%索引计算,1M FLOPs降2.9x。

MoE路由:sigmoid(非softmax,独立打分) + noaux_tc(bias=0退化为纯top-8) + L1归一×2.5 + 1共享专家恒开。

Kimi-K3 · 2.8T · 最激进组合 · 原生多模态

Kimi-K3 是 2.8T 参数 MoE 多模态模型(93层),采用最激进的组合:69层 KDA(线性注意力)+ 24层 Gated MLA(全注意力)+ AttnRes(跨块残差)+ LatentMoE(潜空间896专家)+ SiTU-GLU(有界激活)+ 原生 MXFP4 QAT。

数据流:input_ids + pixel_values -> MoonViT-V2(Conv2d 14x14 + 3D PosEmb + 27层ViT + tpool空间2x2+时间池化 + PatchMerger 4096->7168) -> 占位token替换注入 -> 93层 Block -> lm_head(无MTP)。

KDA 内部:q/k/v_proj(96头x128) -> ShortConv k=4 SiLU -> L2norm -> delta rule递推(S_t = diag(g)·S + β·(v-S·k)·k,带 safe_gate lower_bound=-5 防爆炸) -> 状态 (B,96,128,128) 恒定 -> FusedRMSNormGated sigmoid 输出门。

Gated MLA 内部:Q LoRA(7168->1536->96x192)、KV LoRA+MQA(7168->576->96x256)、use_nope=True(无RoPE!位置由KDA承担)、use_output_gate=True(sigmoid门)。

AttnRes:每12层把 prefix_sum 存入 block_residual 栈(最多8块),每层 attention前和MLP前各做一次 _apply_attn_res(RMSNorm + 1维Linear打分 + softmax + 加权),让深层直接"看到"几十层前的表示。

关键洞察:
1. AllToAll(EP)是MoE最大通信瓶颈: Kimi-K3 896专家AllToAll最重,但LatentMoE在3584维传输(非7168)通信量减半; DeepSeek-V4 FP4权重传输也减半。
2. 线性注意力天然适合PD分离: KDA/DeltaNet状态恒定不随序列增长, Kimi-K3仅27.8GB、Qwen3.6仅32.8GB需迁移。
3. MQA减少TP通信: DeepSeek-V4单头KV replicated到所有GPU, 无需TP切分KV, 减少AllReduce。
4. IndexShare引入新通信: GLM-5.2 full层索引需Broadcast给shared层GPU, 但省73%索引计算, 净收益为正。
5. EP优先放节点内: AllToAll跨节点IB延迟高(~50us), 256/896专家尽量在节点内NVLink(~20us)分布。
